# Ume Choudhary — Portfolio

A static, deployment-ready professional portfolio website.

## Publish on Vercel

### Option A — easiest (GitHub + Vercel)
1. Create a new GitHub repository, for example `ume-choudhary-portfolio`.
2. Upload everything in this folder to the repository root.
3. Sign in to Vercel and choose **Add New → Project**.
4. Import the GitHub repository.
5. Framework preset: **Other**. No build command or output directory is required.
6. Select **Deploy**.
7. Vercel will provide a public `*.vercel.app` URL.

### Add your own domain
1. Buy or use a domain such as `umechoudhary.com`.
2. In Vercel open the project → **Settings → Domains**.
3. Add your domain and follow the DNS records Vercel shows.

## Before publishing
- The site intentionally does **not** claim Oracle expertise because the supplied CV did not provide enough evidence about Oracle work.
- Workday is described as integration coordination/dependencies, matching the supplied CV.
- Client-sensitive case-study details are generalised.
- Replace or expand case studies only with details you are comfortable making public.
- If you later provide a professional headshot, it can be added to the hero without changing the structure.
